## 导出契约

`GET /api/v1/queues/{queue}/export` 返回名为 `{queue}.queue.json` 的 JSON 附件，使用现有版本化 Queue Schema。读取一个已保存声明，验证身份与内容修订，要求通过 `QueueDocument` 完整还原，不猜测旧 Plan 缺失的来源信息。规范化文档的字面格式可能与原始 YAML 不同，但保留受支持字段的精确值，包括大整数、显式优先级零值和 DLQ 引用。

资源读取鉴权不变：默认 operator／auditor，保留现有显式本机演示例外。默认导出移除**全部自由文本标签**；`?include_labels=true` 才明确包含，`false` 等同于省略。脱敏可能改变声明内容／修订。不会隐藏 Queue 名称、Subject、绑定键或 DLQ 引用，这些内容本身也可能敏感。分享前应检查下载文件，不保证自动排除所有秘密。

正文仅包含 Queue 文档，不含保存的 Plan、运行观测、认证凭据或消息数据。依赖**仅保留引用**：导出 Queue 不会导出其 DLQ 目标，也不证明目标存在。这不是消息备份，也不是原子迁移／回滚。导入必须独立验证 Schema／版本、解析依赖、预览每个目标操作，再显式提交。来源 ETag 绝不能当作目标写入前置条件。

响应头包含 `Cache-Control: no-store`、精确加引号的来源 KV 修订 `ETag`、`X-RJS-Export-Scope: single-queue-declaration` 和 `X-RJS-Export-Omitted-Labels` 数量。错误返回 JSON 而非附件：畸形／未知／重复查询参数为 400，声明不存在为 404，不一致／不可还原为 409 `export_declaration_unavailable`，输出超限为 503 `export_limit`。上限：Queue 名称 ≤256 字节、编码后查询 ≤64 字节、含末尾换行的输出 ≤1 MiB、声明读取 ≤3 秒。不返回截断成功。
