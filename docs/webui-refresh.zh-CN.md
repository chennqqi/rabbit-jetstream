# 读取页面刷新与数据新鲜度

[English](webui-refresh.md) | [简体中文](webui-refresh.zh-CN.md)

明确的 `404` 且错误码为 `read_api_disabled` 不作为普通可用性故障处理。总览及节点读取器会清除该来源保留的观测与本机读取时间，显示读取禁用/认证配置提示，与 Queue/Stream 列表边界一致。总览中成功读取的其他来源保持独立。普通 404 或其他 HTTP 状态下的同名错误码不构成此条件。这不会清除用户输入的路由 ID、草稿或保留的写入证据，不推断凭据过期，也不绕过服务端授权；后续授权读取成功后可恢复新观测。

候选总览现实现仪表盘刷新要求。管理服务/账户信息、声明总数和配置节点监控构成一个并发只读批次，不是原子快照。批次完成后等待 10 秒再读取。来源失败/无效或监控节点部分失败/不可达时，间隔增至 20、40 秒，最多 60 秒；成功批次重置为 10 秒。手动刷新替换待执行定时器，不能与进行中的批次重叠。

隐藏标签页不调度新批次。已发出的批次可能完成，隐藏不等于取消。重新显示时按当前间隔安排一个批次，不补发积压请求。离开总览或已认证视图时停止调度并取消页面读取；迟到结果不能恢复已清除证据。调度器不会自动重放编辑器、预览、写入或审计证据请求。

刷新期间保留各面板上次成功数据。网络/服务端/校验失败保留数据及原本机读取完成时间，并显示错误和旧数据标识。权限拒绝会清除该来源的受保护数据。某来源失败不清空成功的其他来源。总览及独立节点页均启用节点监控旧数据保留。

标签页隐藏、刷新失败、观测超过 30 秒或读取时间晚于本机时钟时，标记旧观测。页面打开期间及可见性变化时更新标记。时间表示本机响应完成时间，不是 Broker 采样时间或原子观测时间。30 秒仅为控制台新鲜度阈值，不代表 Broker 健康、HA 或资格门槛。时钟调整可能影响数据年龄展示；节点来源各自的时间戳仍是独立证据。

设置页提供作用于总览、Queue 摘要、Queue/Stream 列表及其 Consumer 集合、Stream 配置/状态、节点页面及独立 Consumer 详情的手动/10/30/60 秒偏好，默认 10 秒。下次间隔使用所选值，失败退避仍以 60 秒为上限。手动模式关闭周期调度，不禁止首次可见读取或手动刷新。切换间隔既不立即派发新批次，也不取消进行中的批次。手动模式下最初隐藏的页面会在首次显示时读取一次。

仅将选定数值保存到 `rjs.overview-refresh-seconds`；非法存储值回退为 10 秒。存储失败时选择保留在当前页面内存，并明确提示未保存。清除会话保留此偏好及语言，不保留凭据或草稿。其他标签页的存储变更不会实时覆盖本页选择，重新加载才读取已保存值。30 秒新鲜度阈值不随刷新间隔变化，因此选择 60 秒时，两次读取之间可能正常出现旧观测提示。

其他只读页面的一致自动刷新、历史指标及资格证据仍未完成，本功能不证明这些要求已完成。

## Queue 摘要刷新

摘要以一个并发批次读取声明指定的 Stream 和精确主 Consumer，不读取 Consumer 列表，不汇总优先级。两个来源保留独立的本机读取完成时间，批次不是原子快照。遵循共享偏好、隐藏暂停、完成后计时及失败退避上限。手动按钮仅刷新对应来源，但两个按钮共享整个批次的进行中保护；下一次自动批次仍读取两个来源。

读取中及网络/不可用故障可保留该来源此前观测与原时间，并明确标记历史数据；失败/隐藏/超过 30 秒/时钟回拨时标记旧观测。缺失、拒绝、明确禁用或无效响应仅清除受影响来源。Consumer 缺失显示未知，不是零积压。主身份无效时不请求 Consumer，也不回退到优先级/列表成员。导航停止调度并隔离迟到读取。不轮询或推进声明、Plan、编辑器 ETag、预览、写入和审计窗口。

## 独立 Stream 配置/状态刷新

Stream 详情现独立于 Consumer 集合调度精确 Stream GET。两者共享偏好和新鲜度规则，但请求进行中保护、完成后计时、退避和读取时间各自独立，不构成原子快照。改变 Consumer 查询只替换其集合读取器/定时器，不重启 Stream 读取。手动刷新 Stream 不获取 Consumers，反之亦然。切换 Stream 或退出会话取消旧读取器与定时器，隔离迟到成功/失败响应。

读取中及不可用故障保留原精确 Stream 配置、计数、副本证据及完整响应，保留原时间并标记历史/旧数据。缺失、拒绝、禁用、身份/结构无效或无法解析的 JSON 响应清除旧 Stream 值及时间，成功的集合行保持独立。Stream 读取器（包括摘要及 Consumer 集合）将无效 JSON 归类为无效，而非不可用。恢复后替换观测，不证明同名重建前后的生命周期连续。不刷新声明、编辑器、预览、审计或写入。

## Queue 与 Stream 列表刷新

列表查询不变时，刷新过程中及不可用/无效响应后保留上次成功页和原读取完成时间。明确提示行、总数及分页属于此查询的历史结果，不代表当前结果；详情链接重新读取资源。刷新成功后替换页面数据并清除提示。改变搜索、排序、偏移或每页数量时，不复用另一查询的行；查询拒绝、权限失败和读取禁用清除旧数据。取消仍能阻止迟到响应恢复数据。

Queue/Stream 列表现复用总览的完成后调度器及设置偏好。每个资源/URL 查询独享读取器和调度器；替换时停止旧定时器并取消旧读取。自动和手动刷新共享单请求进行中保护。调度器重复已提交的 URL 查询，不使用尚未提交的搜索输入或响应页偏移；同查询刷新保留搜索输入。隐藏标签页暂停调度，旧数据沿用 30 秒/失败/隐藏/时钟回拨规则。列表调度器不轮询详情、编辑器、预览、写入、Consumer 或审计证据接口。保留旧偏好键 `rjs.overview-refresh-seconds`，使已保存选择继续生效；设置页现明确标注扩展后的范围。

请求偏移与服务端返回页偏移保持独立。Queue/Stream 列表和 Queue Consumer 列表在集合缩小、响应偏移被截断到总数时，保留原请求偏移。刷新重复原查询；集合重新增长不能让请求悄悄转向旧的截断位置。分页按钮按观测页显式选择新查询，筛选/排序/每页数量变化仍重置到首页。确定性测试覆盖这些模型的缩小、重新增长、重复请求偏移及显式导航。

验证覆盖单批次、完成后计时、退避上限及重置、隐藏暂停、读取抛错、手动刷新、销毁及迟到响应；模型测试覆盖旧数据/时间保留及权限拒绝清除。隔离浏览器回归等待一次真实自动刷新，注入一次信息读取失败，检查数据/时间保留及成功的其他来源，再验证手动恢复；同时运行原写入安全回归。注入错误不是 Broker 故障，测试原有的 Broker 停机场景仍保留。

## 节点集合与详情刷新

两个节点路由共享设置偏好及完成后调度器。每个路由/Node ID 拥有独立读取生命周期；导航停止定时器、取消读取并隔离迟到结果。使用现有单次 `GET /api/v1/nodes` 获取配置端点快照，不虚构逐节点接口或完整成员发现。即使 HTTP 读取成功，节点部分失败或不可达也会触发退避。成功返回空配置端点列表仍不证明健康。

网络/无效响应失败保留旧快照及原读取时间，明确标记其中节点、身份和指标为历史数据；401/403 清除旧数据。新的有效快照整体替换旧数据：ID 缺失、改变或重复匹配均不能沿用先前选定节点的详情。单个来源读取失败不会继承此前指标。来源时间仍与页面本机读取完成时间保持独立；隐藏/失败/超过 30 秒/时钟回拨时标记旧观测。节点调度器不增加节点操作，也不刷新 Queue/Stream/Consumer 详情、草稿、预览或审计证据。

## 独立 Consumer 详情刷新

精确 Consumer 页面按 Stream 和 Consumer 名称限定范围，复用共享偏好和调度器，不枚举列表。同身份刷新在读取中及网络/不可用故障后保留此前观测/时间。缺失、拒绝、明确禁用或无效响应清除旧观测，配置和原始 JSON 同样遵守此边界。`durable` 和 `ack_policy` 若存在必须为字符串，对象值响应不能进入 React 渲染。新的成功读取可替换模式/计数，但不证明同名重建前后的生命周期连续。导航取消旧身份读取器/定时器并隔离迟到结果。隐藏/手动/退避/30 秒新鲜度规则与其他已支持页面一致。Queue 摘要使用上述独立批次；Consumer 集合使用下述独立查询范围调度器。见 [Consumer 行为](webui-consumer-detail.zh-CN.md#当前候选行为)。

## Consumer 集合刷新

Consumer 读取器现将 JSON 解码失败视为无效响应，而非普通不可用；适用于独立 Consumer 详情、Queue 摘要的精确主 Consumer 和 Queue Consumer 集合，与 Stream 读取器一致。畸形 JSON 清除受影响观测/页及原读取时间，后续 503 不能恢复已清除的数据；成功恢复后展示新证据。HTTP 401/403 即使错误体畸形也仍归类为拒绝访问。此分类不刷新或清除其他来源、声明/编辑器版本。

Queue Consumers 标签页及 Stream 实际 Consumer 集合现遵循共享偏好。仅重复已提交的 q/mode/order/offset/limit 查询，不提交或覆盖未发送的搜索输入。每个路由/资源/查询独享读取器和完成后调度器，查询改变或导航取消旧读取/定时器。服务端截断页偏移不改变请求偏移；显式分页才选择新查询。模型旧值保留须显式启用且仅限相同查询：网络/不可用响应保留精确行、总数、声明版本（仅 Queue）及原读取时间，并显示历史/旧数据提示。缺失、访问拒绝、明确禁用、查询拒绝或无效响应清除旧数据；Queue 声明冲突同样清除。无效 Queue/Consumer 链接身份在渲染前被拒绝。

Queue 集合读取不刷新外层声明，也不推进任何编辑器 ETag。变化后的集合声明版本与页头版本保持独立，触发现有版本不一致提示。Stream Consumer 轮询不刷新独立的 Stream 配置/状态快照。两个页面均不把独立来源描述为原子快照，不虚构健康/零值汇总计数。实际 Broker 故障保留明确标记历史的 Consumer 行和时间，与确认缺失/拒绝访问不同。集合调度不触发 Queue 摘要、写入、预览和审计轮询。
