# Queue 删除预检

[English](webui-delete-preview.md) | [简体中文](webui-delete-preview.zh-CN.md)

状态：预检与单次提交删除界面已在源码和本机候选版本实现，尚未发布。持久化结果判定及完整删除体验验收仍待完成。

`GET /api/v1/queues/{queue}/delete-preview` 要求 operator bearer 和原始带引号的声明 `If-Match`。拒绝所有查询参数（包括 `force`）及仅创建条件。不获取锁、不修改资源或声明、不写审计意图或结果。读取超时为 5 秒。

响应标识 Queue 与 Stream，在 `base_revision` 和 `ETag` 中保留原始版本，并返回管理端读取完成时间（`observed_at`）。检查声明身份、版本及原始 KV revision，返回前再次检查 revision。响应使用 `Cache-Control: no-store`。

| 观测 | 响应含义 |
| --- | --- |
| 归属匹配且为空的 Stream | `blocked=false`、`requires_force=false`；不代表授权删除 |
| 归属匹配且含消息的 Stream | `blocked=true`、`requires_force=true`；默认非强制删除会被阻止 |
| 无归属标记或归属不同的 Stream | `blocked=true`；force 不能绕过归属保护 |
| 声明存在但 Stream 缺失 | `stream_present=false`、归属 `unobserved`，省略消息和 Consumer 计数；可能允许仅清理声明 |
| 存在 Consumer | 计数包含所有观测到的 Stream Consumer；当前后端不会仅因其存在而阻止删除 |

成功观测（含被阻止的情况）返回 200。名称或查询参数无效返回 400，bearer 缺失或无效返回 401，角色不足返回 403，声明缺失或已禁用认证接口返回 404，版本改变或声明身份不一致返回 409，编辑条件缺失或无效返回 428，后端失败返回 503。通用资源读取认证可能先于 operator 专用检查拒绝请求。

消息计数是无符号 64 位整数，必须无损解码。计数缺失表示未知，不是零。`blocked` 仅描述观测时默认 `force=false` 的保护状态。`requires_force` 表示观测到消息非零，不代表强制删除安全或被允许。ETag 标识声明版本，不标识 Stream 内容或 Consumer 活动。分步读取不是原子快照。预检不检查 DLQ 依赖方，也不预留删除权限。

界面保留上述区别，展示当前影响与归属，默认关闭 force，要求精确名称确认及显式破坏性影响确认。刷新清空两项确认并关闭 force，切换 force 使确认失效。最终 DELETE 仍须独立检查条件。传输失败或审计失败可能留下未知结果，不可盲目重试。

## 候选删除流程

operator 可在 Queue 详情打开“审阅删除影响”。`/admin/queues/by-name/{queue}/delete` 是独立、由会话持有的流程。先读取声明并保留原始 ETag，再校验完整且匹配的预检响应。无效或不一致的证据不能启用提交。计数无损展示，不把 Consumer 存在标为后端删除阻止条件。

确认后只发送一次 DELETE，携带原始 `If-Match`、精确 `X-RJS-Confirm-Queue`、显式 `force=false/true` 和生成的 `X-Request-ID`。阻止重复提交。有效成功响应仅显示服务端已确认，不表示最新缺失观测或防止重建。任何请求错误或异常成功响应都保持“未知”，包括 409/401/503：浏览器重放请求可能看到与首次尝试不同的结果。只读声明、Stream 和请求审计检查不会解锁重试，也不把资源缺失归因于本次请求。审计检查支持使用精确游标手动读取更早窗口，包括没有匹配记录的窗口。持久化结果判定仍待完成。

审阅及请求证据在 SPA 导航后仍保留于内存。凭据到期保留证据但阻止新请求。提交中禁止清除会话；清除未知结果证据需要确认，且不会取消或回滚服务端操作。同一 Queue 的编辑/创建与删除在会话内互斥。保留编辑器可通过下述单 Queue 交接明确归档，无需清除会话。未提交的删除审阅可以取消，无需清除会话。已提交的删除证据保留到显式清除会话。支持可选择复制的 JSON 和专用删除证据下载。

### 单 Queue 编辑器交接

删除页面提供明确确认的操作，结束此 Queue 的编辑/创建审阅并归档证据。同一 Queue 的所有编辑器条目必须先处于允许交接的状态：idle/load-error/uneditable、可编辑审阅/错误/冲突，或已收到成功响应的 accepted。加载、预览、提交、检查、读取冲突、读取下一次编辑，以及结果未知，都会阻止整个交接。被阻止时按钮禁用，模型执行前仍再次检查。

同步交接先快照保存原始/原文/合并草稿、版本及已接受请求证据，再使旧模型进入只读 archived 状态。归档模型不能恢复编辑或提交。从活动/暂存/已完成创建记录中解除这些模型的引用，不改变其他草稿或凭据。不发送 HTTP 请求，不 apply、不 delete、不退出登录、不清理后端。取消确认不改变任何内容。删除仍是独立、明确的预检操作，重新读取当前声明与版本，绝不将归档 ETag 传入删除尝试。

归档编辑记录可在此 Queue 的详情/编辑/删除路由及过期会话视图中查看和下载。它们是会话内存证据，不是可恢复草稿或结果证明。刷新页面或明确清除会话会丢失记录，因此清除提示包含保留证据；下载文件仍保留在磁盘。取消未提交删除后再进入编辑器，会启动新编辑器，归档仍只读。未知删除结果的恢复仍不允许新写入或交接。

### 证据翻页与下载

每次更早窗口读取均校验请求身份、游标推进和序列范围。读取失败保留此前窗口和游标，可手动重试读取，但绝不会允许 DELETE 重试。游标为 null 只表示本次扫描没有更早的保留范围，不代表历史保留完整。刷新结果观测会将此前检查（含全部已读窗口及读取错误）归档到会话内存。保留各自读取时间，不暗示原子快照或因果归属。

`rjs-queue-delete-evidence.json` 使用 `rjs.queue-delete-evidence.v1` schema，包含原始 ETag、force 选择、预检、关联 ID、结果/错误分类、当前检查及此前检查历史。仅导出明确字段，排除会话凭据、原始错误文本和传输请求头。观测资源与审计正文仍属于敏感数据，会有意保留。下载不发送请求、不改变写入锁定；凭据到期后仍可从保留证据下载。Blob URL 随快照变化和组件卸载替换/释放。清除会话不会删除下载文件。证据不是结果证明、完整历史或重放输入。

本机浏览器验证仅在测试自有 broker 内创建并删除 `live_delete_fixture` 和 `live_delete_unknown`。后者在真实删除成功后故意返回无法解析的 JSON，以验证未知结果锁。不得将测试指向已有服务。不代表远程验收或已发布。

验证：后端只读测试替身在调用写入、锁或 ensure 路径时直接失败；覆盖计数、归属、资源或声明缺失、身份或条件无效、过期及读取期间变化的版本、取消和后端故障。HTTP 测试覆盖认证、超时、no-store/ETag 及错误。本机候选测试记录 `delete-preview.json`，验证真实归属、计数、版本、auditor 拒绝、旧版本冲突及声明未变化，不发送 DELETE。
