# v0.1.0-rc.2 发布说明

[English](v0.1.0-rc.2.md) | [简体中文](v0.1.0-rc.2.zh-CN.md)

此发布候选版本在保持 v0.1 Native Queue 契约不变的前提下，加固运维发行版和 Admin UI。

## 主要改进

- 新增 Chromium 和 Firefox Admin UI 端到端资格测试，覆盖 Queue 生命周期、认证、冲突处理、API 降级、响应式布局、凭据处理和可访问性。
- 新增双语 Roadmap、单机与集群 Compose 指南、Kubernetes 部署指南和运维手册。
- 将 NATS Alpine 运行时替换为固定摘要的 distroless 运行时和静态健康检查器。
- 改进原生 Linux 迁移、故障、Kubernetes、安全、冒烟和打包门禁。

## 生产资格范围

- Linux/AMD64、三个 JetStream 节点、消息流三副本。
- 通过 Native Go SDK `v0.1.0-rc.2` 支持最多八个优先级（`MaxPriority <= 7`）。
- at-least-once 交付；应用必须实现幂等消费。

## 兼容性与限制

- 不兼容 RabbitMQ/AMQP 线协议；本版本通过 Native SDK 实现优先级队列的功能兼容。
- ARM64 镜像仅交叉构建，未取得生产资格。
- 超过八个优先级仍属于实验配置。

请校验 `SHA256SUMS`，部署时固定镜像 digest，并遵循运维手册中的 canary 和回滚流程。
