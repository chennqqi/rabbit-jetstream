# v0.1.0-rc.2 Release Notes

[English](v0.1.0-rc.2.md) | [简体中文](v0.1.0-rc.2.zh-CN.md)

This release candidate hardens the operational distribution and Admin UI while preserving the v0.1 native Queue contract.

## Highlights

- Adds Chromium and Firefox Admin UI end-to-end qualification for Queue lifecycle, authentication, conflict handling, degraded APIs, responsive layout, credential handling, and accessibility.
- Adds bilingual Roadmap, standalone and cluster Compose guidance, Kubernetes deployment guidance, and an operations runbook.
- Replaces the Alpine NATS runtime with a pinned distroless runtime and static health checker.
- Improves native Linux migration, fault, Kubernetes, security, smoke, and packaging gates.

## Qualified Profile

- Linux/AMD64, three JetStream nodes, three stream replicas.
- Up to eight priority levels (`MaxPriority <= 7`) through the Native Go SDK `v0.1.0-rc.2`.
- At-least-once delivery; applications must consume idempotently.

## Compatibility and Limits

- No RabbitMQ/AMQP wire compatibility; this release targets functional priority-queue compatibility through the Native SDK.
- ARM64 images are cross-built but not production-qualified.
- More than eight priorities remain experimental.

Verify `SHA256SUMS`, deploy immutable image digests, and follow the canary and rollback procedures in the operations runbook.
