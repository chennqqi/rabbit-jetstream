# v0.1.0-rc.1 发布说明

[English](v0.1.0-rc.1.md) | [简体中文](v0.1.0-rc.1.zh-CN.md)

这是原生 JetStream Queue 发行版的第一个发布候选版本。

## 主要功能

- 固定 NATS Server/JetStream `v2.14.1`，管理功能不修改上游源码。
- 提供管理 API、内嵌 Admin UI、审计、认证、诊断、迁移、备份恢复和 `rjsctl`。
- Native Go SDK 提供有界严格优先级调度、PubAck、Ack/Nak/Term、背压、重投和重连恢复。
- 提供单机、三节点 Compose 和面向生产的 Helm Chart。

## 生产资格范围

- Linux/AMD64、三个 JetStream 节点、消息流三副本。
- 最多八个优先级（`MaxPriority <= 7`）。
- at-least-once 交付；应用必须实现幂等消费。
- 24 小时、5,000 msg/s、4.32 亿条消息完整性测试，丢失、重复和损坏均为 0。

## 已知限制

- 不兼容 RabbitMQ/AMQP 线协议，现有 AMQP 客户端不能无修改直连。
- ARM64 制品仅交叉构建，未取得生产资格。
- 超过八个优先级属于实验配置。
- 吞吐结果是资格基线，不是通用 SLA。

使用 `sha256sum -c SHA256SUMS` 校验发布包。部署时固定镜像 digest，并在升级 GA 前遵循分阶段 canary 和回滚手册。
