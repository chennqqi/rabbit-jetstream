各阶段发布 P99：0.7–1.7 ms。分阶段 JSON 见 `artifacts/rc3/canary-drill-evidence.tar.gz`（sha256 `f90a4f129c73ead87c894e7f292589ac024fb6793ed65bdd4e5d810258339247`）。

对账语义：canary-drill Queue 为 workqueue（ack 即删除），ack floor 无法用于丢失对账。投递记账是精确的——每条发布的消息都投递给 Queue 唯一声明的消费者，因此 `received == published` 且 `corrupt == 0`、`management_5xx == 0` 证明零丢失/零损坏。
