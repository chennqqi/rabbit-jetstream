# 连接订阅详情方案

[English](webui-subscription-design.md) | [简体中文](webui-subscription-design.zh-CN.md)

状态：已实现并在本机验证推荐的认证 `resources:read` 可见性策略、有界 monitoring/API 契约和显式加载 WebUI。精确客户端名称／用户／账户／MQTT 身份搜索也已独立实现。本机有界 1,000 行延迟／RSS／客户端锁资格验收已通过；正式生产主机资格验收仍须独立执行。

## 已核实的上游约束

固定版本 `upstream/nats-server/server/monitor.go` 支持精确 `cid` 配合 `subs=detail`。`newSubsDetailList` 在客户端锁内枚举该客户端订阅，没有独立订阅 offset/limit；连接分页不会限制订阅数量。`SubDetail.sid` 为字符串，`cid` 为 uint64，`msgs`/`max` 为 int64。订阅身份为节点 ID + CID + 精确 SID，不是 Subject、队列组名或数字化 SID。多个订阅可以拥有相同 Subject。

`ConnInfo.subscriptions` 与订阅详情在同一客户端锁内生成。数量为零时，JSON `omitempty` 可省略空详情数组；数量大于零时，缺少详情行绝不能解释为空订阅集合。响应 `total` 仍为节点连接数，而非匹配订阅数。应检查完整赋值路径，不能混淆同名近似的局部变量 `totalClients`。

## 元数据可见性决策

建议：复用已有 `resources:read`，允许已认证 operator 和 auditor 查看运行元数据 Subject、队列组及 SID 和数值计数。排除账户/身份标签、客户端名称、IP/端口、凭据、JWT、证书及上游原始对象。明确运行标识可能包含业务敏感文本，不能公开发布。还须考虑已有显式本机演示资源读取例外：批准此选项将包括演示模式资源读取中的这些运行字段，除非另行批准限制策略。

备选：仅 operator 可查看这些运行标识，auditor 继续查看数值连接诊断。这需要独立的端点权限强制检查及对应会话/UI 能力，仅禁用按钮不够。不能静默改变已有共享只读角色的含义。

负责人已确认推荐的共享认证读取策略。该策略不允许访问消息正文或 publish/ack/replay 操作，不会新增角色。字面 loopback demo 模式继续沿用已有资源读取例外；非 loopback 部署必须由已认证 operator 或 auditor 访问。

## 已实现的有界读取契约

- 独立显式读取一个精确节点/CID；不向周期刷新的连接列表或基础详情加入 `subs=detail`。
- 复用完整唯一节点解析及共享五秒期限。先读取数值详情，报告数量超过 1,000 时在请求订阅行前拒绝扩展。计数缺失表示未知，不是零。
- 符合条件时以 `auth=false`、`subs=detail` 请求精确 CID，重新核对节点/CID、来源时间、报告数量、行数及 SID 唯一性。连接缺失与观测不可用保持区分。
- 响应沿用 2 MiB 上限，接受行数最多 1,000。预检与扩展之间的增长仍可能超限，须明确返回超限/不可用，不能静默截断后成功。预检不证明上游 CPU/分配有界，也不能消除客户端锁开销。
- SID 保留精确字符串。实现前明确 SID、Subject 和队列组的有界 UTF-8/控制字符校验，不强制转换任意标识，不合并重复 Subject。数值计数保持精确；可选 `max` 缺失表示未报告，不虚构限制。
- 接受完整有界观测后，可按 SID 确定性排序并进行本地分页/过滤，但必须明确作用于该完整观测。刷新产生新观测，不是跨请求稳定快照。超限集合保持明确不支持，直到另一个批准的数据源可提供有界分页；这不满足任意规模订阅浏览。
- UI 初始未观测，仅显式操作加载，说明元数据敏感性/限制，区分无订阅、连接缺失、拒绝、不可用、超限和数据不兼容。不从传输订阅推断 Consumer 所属关系、积压或健康。会话清除或确认拒绝/身份变化时清空数据。

1,000 行上限与显式加载是建议实现默认值，并非测得的性能验收结论。不会修改服务器子树、向浏览器暴露监控端口、变更订阅或操作远程负载。

## 必需验收证据

单元/契约测试：非数字与前导零 SID 保留；拒绝重复 SID 但不合并重复 Subject；精确大计数；零数量数组缺失与非零数量畸形数组区分；错误 CID/节点；截断/超大响应；数量增长；脱敏错误；期限/取消；选定角色策略在上游 I/O 前强制执行。

真实隔离 NATS 测试：仅创建自有客户端/订阅，不发布消息，包含重复 Subject、不同字符串 SID、队列组、通配 Subject、取消订阅/变化、零订阅和超限案例。仅停止自有进程/套接字。所有辅助工具本机构建并记录制品指纹。

浏览器测试：仅显式加载、真实完整观测过滤/分页、行身份、错误/恢复、角色拒绝及会话清除、双语长标识、键盘/可访问标签及窄屏截图。继续独立规模/锁开销评估和完整 WEB-019 搜索工作；有界演示通过不代表整体完成。
