# 管理控制台用户手册

[English](console-user-guide.md) | [简体中文](console-user-guide.zh-CN.md)

面向 Rabbit JetStream 管理控制台（`/admin/`）操作人员的任务导向手册。本手册说明界面上能做什么、怎么读；架构与服务端配置见 [Operations](operations.zh-CN.md) 与 [Configuration](configuration.md)。

## 登录

- **用户名/密码**：本地账户由管理员开通（见[本地账户认证](local-auth.zh-CN.md)）。会话短时效且仅存于页面内存。
- **SSO**：部署配置了 OIDC 时，登录页出现"使用企业 SSO 登录"按钮。
- **恢复或自动化 Token**：运维人员可直接粘贴 Bearer Token 登录。
- **会话过期**：凭据到期后控制台保留导航并提供**重新登录**按钮；草稿与证据保留在页面内存，直到清除会话。
- **语言**：右上角按钮在 English 与 简体中文 间即时切换；选择保存在本地。

## 读懂数据

**导航分组**：资源（总览、Queue 列表、Stream 列表、Consumer 列表、节点列表）、运维（审计、诊断包、运维告警）、治理（批量变更、访问与设置、租户访问管理）。

**状态徽章**把观测结果翻译为优先级：

| 徽章 | 含义 |
|---|---|
| 一致 | 声明 Queue 的 Stream 与声明一致；Consumer 配置未检查。 |
| 降级 | Stream 降级或配置不一致——需要排查。 |
| 缺失 | 声明的 Stream 不存在。 |
| 不可用 | 观测本身失败——计数未知，不是零。 |

**语义约定**：计数是*观测*值，不是声明值；不同页面读取时间不同，不是同一原子快照；未知保持未知（绝不显示为零）。细节折叠在各页的"关于这些数字与状态"中。刷新指示器（"刷新于 … · 每 10 秒自动"）显示数据新旧；数据暂停、失败或超过 30 秒时出现过期横幅。

**Plan 版本**是截断的哈希；Copy 按钮把完整版本号放入剪贴板。

## Queue 生命周期

### 查找与查看

打开 **Queue 列表**查看声明 Queue 的观测状态、消息数、Consumer 数、存储与 Plan 版本；用"Queue 名称包含"筛选。点击 Queue 进入详情：摘要并排展示观测 Stream 计数与声明配置，标签页提供配置（原始声明）、路由、消费者与事件。

### 创建

1. 点击 Queue 列表页头的**创建 Queue**。
2. 填写名称、Subject（每行一个）、副本数、存储类型与上限。模板可预填字段。
3. 点击**准备创建草稿**，再**预览变更**。预览仅是建议——确认前不会应用任何内容。
4. 勾选**我已审阅此预览并授权应用此草稿**，点击**应用已审阅草稿**。创建操作会被审计。

### 变更

在 Queue 详情页点击**编辑草稿与预览**：编辑 JSON 草稿，点击**预览变更**，审阅差异，授权后**应用已审阅草稿**。并发变更冲突会以 ETag 错误拒绝——重新加载后再次应用你的修改。每次应用都是条件写入并被审计。

### 删除

**审阅删除影响**运行预检：所有权、消息数、Consumer 数与 DLQ 依赖方。删除非空 Queue 需要**force** 勾选、输入精确 Queue 名称，并勾选影响确认。若结果不确定（发出请求后报错），控制台会锁定重试——保存证据、检查 Stream 是否仍存在，再人工决策。下载删除证据 JSON 存入工单。

## Stream 与 Consumer

**Stream 列表**与 **Consumer 列表**是只读观测，包含在控制台之外创建的资源。Consumer 详情展示待投递/待确认计数用于积压排查；Consumer 诊断提示链接到 [Operations](operations.zh-CN.md) 的排查步骤。

## 节点与连接

**节点列表**显示每个已配置监控端点及其读取状态（徽章）。节点详情展示版本、运行时、JetStream 状态与各来源读取证据；连接按节点搜索，可按需查看订阅明细。

## 审计

**审计**将每次写意图与其结果配对。按请求 ID、资源、操作者、阶段、操作、结果与时间窗（RFC3339）筛选后翻页。**准备导出**把筛选窗口下载为 JSON 存入工单。单窗口最多扫描 256 个序号；缩小时间范围才能到达更早记录。

## 诊断包

**诊断包**从管理进程生成仅元数据的 ZIP（无消息、无凭据）：含 SHA-256 的 manifest，同时只允许一个采集任务，创建十分钟后过期且不跨重启保留。创建 → 查看清单 → **准备下载** → 保存文件。

## 运维告警

**运维告警**是随货 Prometheus 规则的只读投影（控制台不发送通知——告警到人需要 Alertmanager，见[运维配套清单](operations-companion.zh-CN.md)）。状态：**firing**（触发，红色）、**pending**（待触发）、**recovered**（本进程观测到触发转未触发）、**inactive**（当前未触发）。"告警覆盖不完整"提示随货规则在后端缺失。

## 批量变更

**批量变更**逐 Queue 应用版本化更新包：上传、预览全部目标，然后逐项单独确认。设计上不存在"一键全部提交"。

## 访问与设置

- **已验证会话**：你的身份、角色、到期时间与权限；**清除本机会话**（在身份面板内）登出并丢弃内存中的草稿。
- **偏好**：语言与刷新间隔保存在本地。
- **租户访问管理**（平台管理员）：创建本地账户、设置租户成员关系与角色、禁用或删除账户。
- **兼容性**（从访问与设置进入）：构建版本、内嵌 UI 身份、SDK 契约与服务端能力。

## 租户切换

拥有多租户的账户通过身份面板的"当前租户"选择器切换；URL 携带租户（`/admin/tenants/<tenant>/…`）。切换会丢弃当前租户的草稿（需确认）。
