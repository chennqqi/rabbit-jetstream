## 已核实的集成点

`tools/rjsctl/diagnostics.go` 使用固定来源、每响应 4 MiB 上限和 ZIP 清单。Queue／Stream 列表只采样首个最多 200 项页面，不是完整导出。`internal/redact.JSON` 保留精确数字，畸形 JSON 不返回原始字节。文本／嵌入秘密仍需更严格的浏览器导出策略。

`management/internal/api/handler.go` 提供认证身份与 `AuditBackend.RecordAudit`。当前审计辅助函数写死 Queue 身份及写入结果错误，不能不加修改用于下载。仅靠 `read_auth.go` 不够：本地演示可匿名读取，但本提案要求每个任务请求具备身份。`app.go` 管理退出和 HTTP 超时；任务线程须绑定应用退出，不能脱离处理器后无限存活。当前 Handler／OpenAPI 没有诊断路由。

## 已批准决定

已实现：实例内有界内存任务，仅认证 operator 使用，状态／下载／取消仅限创建者。不提供匿名演示例外或 auditor 包访问。重启后任务与数据丢失，不后台恢复。不添加服务端文件、外部存储或凭据。磁盘任务仍不在已批准范围内。

## 批准后拟定契约

- 显式 `POST /api/v1/diagnostics/jobs` 仅接受带版本的元数据配置，不接受任意路径、URL、命令、请求头或来源列表。拒绝未知／重复字段并限制请求字节。服务端不启动子进程或 CLI，不通过自调用 HTTP 转发凭据；经有界强类型数据提供者采集。
- `GET /api/v1/diagnostics/jobs/{id}` 读取状态，独立鉴权下载端点仅提供已完成字节。取消撤销访问并终止采集。ID 至少 128 位随机，不是持有即授权的凭据。每次操作重新核验身份及创建者，未知任务与其他创建者任务不可区分。Token 过期／撤销后禁止后续访问，工作线程不保留 Token，URL／存储不放 Token。使用身份作为归属键前须验证唯一性。
- 初始预算提案：每实例一个在途采集、最多两个保留任务，采集总时限 30 秒，每输入 4 MiB，未压缩输出总量 8 MiB，ZIP 8 MiB，自创建起十分钟过期。这是准入预算提案，不是已测内存／性能。开工前预留槽位／字节，限制编码／压缩开销，超限明确拒绝；无无界排队。限制并发下载并处理过期竞态，防止在途字节引用绕过内存记账。
- 状态为采集中、就绪、部分完成、失败、取消、过期。ZIP 关闭、清单／摘要校验和必要审计记录完成后才发布归档字节。省略来源须在清单可见并标为部分完成，不能称“完整”。失败／取消／过期不暴露字节。定时清理和访问时过期校验一致，迟到回调不能重新发布；退出取消线程并释放内存。
- 仅元数据：不含消息载荷、凭据、环境变量、源码文件、客户端订阅或任意日志。共享 JSON 脱敏之外须显式限制字段／来源；原始错误与 Prometheus 文本须经审查的清洗或省略。Queue／Stream 采样标明首个页面上限和采集时间。HTTP 只返回 200 行并不限制后端枚举成本：纳入来源前，须具备取消和硬工作量预算。不得称完整账号备份或原子快照。
- 采集前记录创建意图，发字节前记录下载授权；审计取消及终态。审计不可用时禁止首次执行或字节释放。区分授权、开始传输、服务端写出完成及客户端收到；服务端成功不证明浏览器已保存。开始传输后结果审计失败不能再用第二个 HTTP JSON 响应补救，须在服务端证据中暴露，不能宣称完整审计成功。不把 Queue 写入不确定性直接用作下载重试规则。
- 响应使用 `Cache-Control: no-store`；下载名由服务端安全生成，固定 ZIP 类型，不提供外部重定向、公共分享链接或任意范围／多段传输。浏览器使用内存 Token fetch，限制下载字节，检查状态／类型／长度，撤销对象 URL，过期／退出／导航时清理引用。必须显式创建，页面刷新不能触发采集；创建中断不自动重复，丢失创建响应须有有界且仅创建者可用的查询／恢复契约。
