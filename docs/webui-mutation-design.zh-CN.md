# WebUI 写操作恢复设计

[English](webui-mutation-design.md) | [简体中文](webui-mutation-design.zh-CN.md)

日期：2026-09-09。范围：[逻辑审查](webui-logic-review.zh-CN.md) L-03/L-06/L-09/L-10 的**隔离原型**可执行补充，不代表生产接入或验收。

## 状态与动作契约

| 结果/状态 | 可以改变什么 | 允许的恢复动作 |
| --- | --- | --- |
| 编辑/复核 | 只改草稿，保留不可变的原始配置和版本 | 校验、语义差异、明确提交 |
| 提交中 | 固定请求快照，同步防护重复派发 | 等待结果，关闭 UI 不保证取消请求 |
| 已接受 | 期望声明推进，保留旧观测 | 独立观测是否收敛 |
| 冲突 | 当前声明不同于原版本，本次写入拒绝 | 对照原值/本地/当前值，明确将本地变更保留到当前配置上，重新编辑并复核 |
| 无权限/过期 | 这些样例不修改资源，内存保留草稿 | 明确模拟恢复访问，再编辑/复核，不索取真实凭据 |
| 结果未知 | 可能已写入，不能报成功或自动重试 | 使用同一关联 ID 核查资源和审计；关闭后仍保留未决操作入口 |
| 部分生效 | 部分资源操作完成，不能假设回滚 | 核查实际字段，再明确进入人工修复复核 |
| 资源已确认、审计缺失 | 资源结果已知，审计仍不完整 | 分别呈现，资源确认不等于审计成功 |

原值/本地/当前值和模拟 KV 版本分开保存。只有用户明确选择后，才将本地语义变更复制到当前配置；没有改过的字段保留当前值。真实环境中再次提交仍可能冲突；原型的一次性故障样例恢复后默认成功，仅用于展示恢复过程，不绕过真实 ETag 检查。

未知/部分生效在核查前阻止普通刷新和新提交；未决期间不能切换样例身份。编辑器有未保存修改时，浏览器历史导航保留编辑上下文；卸载页面提示内存状态可能丢失。用户确认刷新浏览器后仍会丢弃全部模拟会话数据，这不是持久恢复存储。

## 具体样例与限制

- 冲突：另一模拟写入者将 ACK 等待改成 90s（原值已是 90s 则为 120s），KV 版本加一；本地 45s 在明确恢复并重提之前不写入。
- 响应未知：本样例的资源变更实际成功，核查后揭示声明和观测。这只演示一种不确定结果，不覆盖所有超时结果。
- 部分生效：Stream 最大保留时间为请求值，Consumer 配置仍是之前的观测；期望声明和 KV 版本保持原值。不自动回滚或重试。
- 审计结果缺失：核查确认资源后，会话历史仍保留审计缺失提示。
- `mock-op-1` 等关联 ID 是本地样例标识，不是生产标识。会话内 `queue.apply`、`resource.inspect` 记录描述原型动作，不是服务端持久审计。

这些确定性样例不实现认证、真实 ETag 并发、元数据/内容版本对账、持久审计查询、通用 Broker 部分失败恢复或删除。生产结果必须来自服务端及资源证据，不能由前端场景选择器决定。核查期间真实读取失败、无法消除的不确定性，仍是必须补的集成场景。

## 验证与审查证据

首轮浏览器测试发现恢复按钮默认动作缺陷：按钮重绘为表单提交按钮后，意外进入复核。取消恢复点击的默认动作后修复。回归现在明确断言冲突/权限/部分生效恢复后返回可编辑字段，再单独点击复核。

最新完整验证：**26 项浏览器检查、15 项模型测试、4 项打包测试；15 个状态自动无障碍扫描零违规；零浏览器错误、零外部请求**。构建与格式通过，覆盖重复提交派发和草稿的浏览器历史保护。[结果](../design-prototypes/webui/evidence/results.json)、[视觉 QA](../design-prototypes/webui/design-qa.zh-CN.md)。
