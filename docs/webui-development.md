## Browser SSO (WEB-025)

The approved browser architecture is now implemented as OIDC Authorization Code with PKCE S256 and no service cookie/session. The browser retains only one transient state/verifier record in `sessionStorage`, deletes it and removes callback parameters before exchange, then keeps the verified ID-token bearer in page memory through the existing session model. Management uses only its discovered fixed token endpoint, validates the returned ID token and mapped role, and never returns refresh/access tokens or raw provider errors. Static bearer entry remains available. Deployment configuration, Helm fail-closed relationships, public OpenAPI bootstrap contracts and bilingual operator guidance are included.

Backend discovery/JWKS/token-exchange tests, API/config/OpenAPI tests, 382 runnable frontend tests (plus one expected Windows symlink skip), the candidate build, four-file promotion and byte verification passed. The final embedded Chromium run `artifacts/webui-live-z6DGZP/report.json` passed 135 checks against management SHA-256 `915cf6b0b9edb05b05624a96a93fc7667b2b174bb1648e67a3ea7a241bda107c`. The preceding `PsuCHz`, `vVswdk` and `dHO1XX` runs are retained failures: their Connection-detail assertion incorrectly assumed an automatic successful observation inside a fixed window despite the documented unavailable-history/backoff model. The final harness uses an explicit successful read for that integration evidence and leaves exact automatic scheduling/backoff to deterministic model tests; its check label no longer claims periodic-detail coverage. This qualifies the local implementation and embedded integration, not an external production IdP, final release freeze, Canary or native-host qualification.

## Bounded metadata diagnostics (WEB-024)

The owner approved instance-local, bounded in-memory diagnostic jobs. The candidate now exposes authenticated operator-only create, creator-only status/cancel/download, fixed 30-second collection and ten-minute expiry, one active collector, two retained identities and an 8 MiB archive limit. Expiry has an actual timer as well as access-time enforcement; cancellation, shutdown and stale completion cannot republish bytes. Application shutdown closes the store before the JetStream client.

The fixed in-process collector includes build identity, server capabilities, redacted account metadata, controller status and projected node observations. It accepts no URL, path, command, headers or source selection. Raw monitoring errors are replaced with a static availability message and URL credentials are removed. Queue/Stream inventories, messages, subscriptions, logs and environment remain excluded because existing enumeration APIs do not yet prove a hard work bound. Create, cancellation, download authorization and server write completion are audited; server completion is explicitly not browser-receipt proof.

The bilingual `/admin/diagnostics` workspace is permission-gated, never creates on refresh, displays partial/terminal states and the manifest, validates ZIP media type and length before creating a Blob URL, and revokes that URL on replacement/navigation.
