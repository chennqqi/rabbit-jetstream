## 首轮问题

- [P1] 垂直位置偏移：实现顶栏 100px，来源约 70px；详情起点 y=409，来源约 362，排查操作被推到参考视口下方。需缩减顶栏及区块间距。
- [P2] 指标说明换行增加面板高度；保留修正后的语义，缩短说明但不隐藏内容。
- [P1] 窄屏访问按钮隐藏文字后缺少可读名称，需要显式双语标签。
- [P1] 排查说明在浅色背景上的对比度不足，需要加深文字。

字体：保留系统回退，需修正说明换行。布局：两栏宽度约 780/382px 已接近，纵向节奏不符。颜色：沿用深绿/浅色，排查文字对比度失败。素材：RJS 文字与授权 Tabler 图标，无伪造图片。文案：有意纠正指标可能重叠及 Lag 未知语义，未删减数据字段。

## 验证

[首轮结果](evidence/results-pass1.json)：11 项交互通过，无控制台错误、无外部请求。无障碍扫描在对比度和窄屏按钮名称处失败。已测试桌面、复核、英文及 375px 状态，截图人工对照尚未通过。

## 第二轮及最终验证

首轮四项问题已修复：顶栏 70px，详情起点 y=362.80，主辅栏宽度 779.75/382.25px，面板高度 553.56px，排查区起点 y=931.36，在原图视口内可见。缩短指标说明但不删字段、不改数值；访问按钮新增双语可读名称，排查文字加深。窄屏明确保留模拟数据/部署模式标签。

修复后证据：[整体对照](evidence/comparison.png)、[局部对照](evidence/comparison-detail.png)、[复核](evidence/review.png)、[375px](evidence/mobile.png)、[手机编辑](evidence/mobile-edit.png)、[1440px](evidence/viewport-1440.png)、[768px](evidence/viewport-768.png)、[手机英文](evidence/mobile-english.png)。整体和局部均将来源/实现置于同一输入中查看。响应式及编辑状态没有选定的对应设计稿，单独检查可用性，不声称像素匹配。

最终 [浏览器结果](evidence/results.json)：**13 项检查通过**，页面/控制台错误为零、外部请求为零；**六个扫描状态均无无障碍违规**（中文桌面、英文桌面、复核、375px 中文、375px 编辑、375px 英文）。另有 3 项模型单测、4 项模板打包测试、生产构建及格式检查通过。打包测试不代表已经部署。

五项视觉检查：字体采用系统回退，尺度接近且可读；主要布局和比例已对齐；保留深绿/浅色语义并改善对比度；使用图标库和文字 RJS 标识，无伪造素材替代；文案有意纠正指标语义，保留全部选定夹具字段。已检查状态中未发现剩余可执行的 P0/P1/P2 问题。

P3 后续项：具体字形、线性图标轮廓与生成图片及不同系统存在差异，不声称逐像素相同。手机英文标签有意采用横向滚动，键盘可达。完整生产无障碍审计、Firefox/Safari 执行及真实 API 行为不在本次原型证据内。与原图的尺寸对照仅针对 1487 × 1058 中文概况页。

证据位于忽略版本管理的 `evidence/`，启动本地预览后通过 `npm run test:ui` 可重建。测试未使用远程验收主机或生产数据。

## 逻辑审查修正轮次（2026-09-09）

范围：选定双栏概况，以及获授权的 Consumer 列表/详情和状态修正。本结果是视觉/原型门槛，不代表[逻辑审查](../../docs/webui-logic-review.zh-CN.md)中的真实 API 要求已关闭。

首轮对比发现 P2 偏移：较长指标文案及默认高度的 Consumer 链接将副本和排查区域下推。缩短说明，为行内链接设置独立 24px 最小目标、去除多余内边距和自动外边距。重新采集，并在同一输入中查看[全图](evidence/comparison.png)与[局部](evidence/comparison-detail.png)的原图/实现对照；两侧均为 1487×1058 CSS/像素、密度 1。最终详情顶边 362.80px，列宽 779.75/382.25px，面板高度 553.77px，排查区顶边 931.56px。Consumer 实名、模拟 KV 版本、陈旧页脚是有意的逻辑纠正，不是意外视觉偏差。

额外逐张检查：[列表第 2 页](evidence/consumers-page2.png)、[详情](evidence/consumer-detail.png)、[读取失败](evidence/consumer-stale.png)、[手机列表](evidence/mobile-consumers.png)、[手机详情](evidence/mobile-consumer-detail.png)。长页截图先滚动到顶部，避免固定导航错位的截图伪影。新增状态无独立选定原图，只验证可用性，不声称逐像素一致。

字体：保留系统字体和可读层级。间距：恢复概况节奏，手机详情堆叠，列表使用有名称且键盘可聚焦的横向滚动区域。颜色：保留语义色并检查警告文字。素材：继续使用 Tabler 和文字标识，没有生成素材替换。内容：明确指标归属、预期资源、声明/观测和模拟限制。已检查范围内无剩余可执行的视觉 P0/P1/P2，原有字体/图标 P3 差异保留。

最新验证：**19 项浏览器检查、8 项模型测试、4 项打包测试；11 个无障碍状态自动扫描零违规；零浏览器错误/外部调用；构建与格式通过**。测试准备已修正独立案例之间的语言/会话重置。真实授权、并发、持久审计、后端失败行为仍未验收；模拟样例不关闭生产 P1。

## 写操作恢复轮次（2026-09-09）

重新采集选定概况与最新实现，1487×1058、密度 1，在既有全图/局部对比输入中一起检查。概况几何和素材未改变。新增结果弹窗沿用字体、语义警告色、表格间距、响应式弹窗容器。已打开检查[桌面冲突](evidence/mutation-conflict.png)、[375px 冲突](evidence/mobile-mutation-conflict.png)、[未知结果](evidence/mutation-unknown.png)、[部分生效核查](evidence/mutation-partial.png)；这些额外状态不声称与选定原图逐像素匹配。已检查尺寸下按钮可见、文案可读。

发现并修复一个阻断行为：恢复点击继承新渲染提交按钮的默认动作，意外进入复核。通过 `preventDefault` 和浏览器断言确保必须独立点击复核。最终通过 26 项浏览器检查、15 项模型测试、4 项打包测试；15 个状态自动无障碍扫描零违规，零浏览器错误/外部调用。无新增可执行视觉 P0/P1/P2，保留原字体/图标 P3 差异。[恢复契约及限制](../../docs/webui-mutation-design.zh-CN.md)明确保留真实 API 验收缺口。

final result: passed
